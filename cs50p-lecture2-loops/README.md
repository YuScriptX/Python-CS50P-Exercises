# CS50P – Lecture 2: Loops

These are my practice exercises for Lecture 2 of Harvard’s **CS50P** course.

## 🧠 Concepts covered
- `for` loops  
- `while` loops  
- Input validation with loops  
- Iteration over lists and strings  
- Using `len()`  
- Dictionaries and list of dictionaries  
- Nested loops  

## 🧩 Exercises
| # | Exercise | Description |
|---|-----------|-------------|
| 1 | **Count 1 – 10** | Use a for-loop to print numbers from 1 to 10 |
| 2 | **Countdown (while)** | Count down from 5 to 1, then print “Blast off!” |
| 3 | **Sum 1 – 100** | Calculate total of all numbers 1 through 100 |
| 4 | **Print word N times** | Repeat a word N times using a for-loop |
| 5 | **Validate positive number** | Keep asking until user enters a positive integer |
| 6 | **List sum and average** | Calculate sum and average of numbers in a list |
| 7 | **Count even and odd numbers** | Count how many numbers are even or odd |
| 8 | **Collect names (while)** | Collect names until “stop” is entered |
| 9 | **Dictionary iteration** | Loop through key–value pairs and print them |
| 10 | **List of students (dicts)** | Work with a list of dictionaries and compute average age |
| 11 | **Search student by name** | Find a specific student in a list of dicts |
| 12 | **Multiplication table (nested loops)** | Generate tables 1–10 using nested loops |
| 13 | **Matrix iteration (nested lists)** | Loop through a 3×3 matrix and print values |

## 📚 Notes
Lecture 2 explores **iteration** — repeating actions efficiently.  
By combining `for` and `while` loops, input validation, and nested structures, you learn to process collections like lists and dictionaries.
