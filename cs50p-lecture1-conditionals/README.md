# CS50P – Lecture 0: Functions & Variables

These are my practice exercises for Lecture 0 of Harvard’s CS50P course.

## 🧠 Concepts covered
- Variables and data types
- Input and output
- Functions and parameters
- Return values
- Basic arithmetic

## 🧩 Exercises
1. **Hello, world** – simple print statement  
2. **Greet by name** – user input with f-strings  
3. **Sum of two numbers** – converting input to int  
4. **Square function** – defining and calling a function  
5. **Main function** – `if __name__ == "__main__"` pattern  
6. **Convert to uppercase** – using `.upper()` method  
7. **Area of rectangle** – function with two parameters
