# CS50P – Lecture 3: Exceptions

These are my practice exercises for Lecture 3 of Harvard’s **CS50P** course.  
This folder includes exercises 1–6, focusing on basic exception handling.

## 🧠 Concepts covered
- `try` / `except`
- Handling `ValueError` and `NameError`
- Using `else` with `try/except`
- Reprompting user input
- Creating a simple `get_int()` function
- Using `pass` to ignore specific errors

## 🧩 Exercises
| # | Exercise | Description |
|---|-----------|-------------|
| 1 | **Try/Except Input** | Catch invalid input (`ValueError`) |
| 2 | **Prevent NameError** | Handle undefined variables safely |
| 3 | **Try/Except with Else** | Test division and handle invalid input |
| 4 | **Reprompt Until Valid Number** | Loop until a valid integer is entered |
| 5 | **get_int Function** | Reusable function for safe integer input |
| 6 | **Using pass** | Skip over invalid values while looping |

## 📚 Notes
Lecture 3 teaches **error handling** — how to prevent your program from crashing when something goes wrong.  
By practicing these examples, I learned how to safely handle input and make Python programs more reliable.
